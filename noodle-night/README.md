# NOODLE DISCO — NIGHT MIX

2026年10月31日分。コバルトブルーのフロアにネオンの麺が踊る、停止と解放の作品です。
DAYの「1本を引っ張る」操作に対し、NIGHTは「画面全体の動きをためて解放する」操作を主役にします。音声は使用しません。

## 操作

- 画面を長押し：ダンスが静まり、麺が中心方向へ圧縮します。
- 離す：ためた動きをバーストとして解放し、通常のダンスへ戻ります。
- キーボード：Canvasへフォーカスし、Spaceを押し続けて解放。Escapeでキャンセルします。
- 右上の小さな「＋」：調整UIの開閉。Tempo／Tension／Burst、一時停止、Reset。
- UI操作は作品の長押しを発生させません。

## 実装

`../assets/noodle-engine.js` の `mountNoodles({mode: 'night'})` を使用します。
JavaScriptが制御点・ばね・減衰・入力状態を管理し、Canvas 2Dが曲線を描画します。
外部ライブラリ、外部素材、音声、GLSLや物理エンジンは使用しません。

`index.html` を含むリポジトリ全体を静的HTTPサーバーで配信します。GitHub Pagesのサブパスに対応した相対URLです。

## 受け入れ条件

- 初期状態は位相差を持つダンス。調整UIは閉じています。
- 長押し→静止に近づく→圧縮→解放→バースト→通常復帰を連続して遊べます。
- 押したまま画面外へ移動して離しても、操作が固まりません。
- Pointerキャンセル／Escape／フォーカス喪失はバーストを発生させず、安全に通常状態へ戻ります。
- 調整UIとCanvasの入力が干渉しません。
- リサイズ・縦横変更で麺の配置が破綻しません。
- OSのモーション低減設定では自律アニメーションを抑えます。
- ローカル検証・3人レビューの結果はPR本文を参照してください。実機のSafari・Androidで未検証の場合は、その旨を明示します。
