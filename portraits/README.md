# 言葉の肖像 — 芥川龍之介 × 羅生門

`portraits/` を含むリポジトリ全体を静的HTTPサーバーで配信してください。

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

`http://127.0.0.1:8766/portraits/` を開きます。ビルド・npm installは不要です。
ES ModulesとModule Workerを使うため、HTMLを `file://` で直接開く方法には対応しません。

## 体験

原稿をクリック・タップすると再生／一時停止します。キーボードでは原稿にフォーカスし、Enter／Spaceでも操作できます。
左のキャプション下にも再生・リプレイ・完成形・調整を一行で配置しています。詳細情報は調整内にあります。
タイトル、作家名、本文が浮いて消え、紙面が傾いてから文字の雨が肖像を作ります。
本文はランダムな一文字／語句単位で消去できます。雨はまばらな状態から不規則な豪雨へ移行します。
調整パネルは初期状態で閉じています。設定変更後は完成形を表示するので、「最初から」で演出を確認してください。
PNG保存、一時停止、進行度の移動、初期値への復帰に対応します。

初期値：文字上限4,800／倍率1.2／白抜き60%／輪郭重視60%／ランダム回転。
雨の密度と所要時間は、実際の配置文字数によって変わります。上限文字数を満たすために白い領域へ配置することはありません。

## 構成と再利用

- `lib/mapping.js`：画像の明暗・輪郭、白抜きマスク、領域に応じた文字サイズと配置。DOM非依存。
- `lib/rain.js`：種付き乱数による降雨の時刻・速度・風、同時落下上限、着地順。DOM非依存。
- `mapping-worker.js`：重い画像解析と配置計算を別スレッドで実行。
- `app.js`：Canvas 2D描画、紙面の投影、冒頭の演出、操作と読み込み状態。
- `rashomon.js`：本文。`assets/rashomon-source.html` からルビ・注記・奥付を除去したもの。外字はUnicodeで保持。
- `assets/`：ユーザー指定の添付肖像、フォント、原典外字画像、本文原本とサムネイル。

画像・フォント・外字は同一オリジンから配信します。Google FontsやWikimediaへの実行時アクセスはありません。
フォント・画像の読み込み、Workerでの配置準備中は操作を無効化してローディングを表示します。
失敗時は再試行できます。着地文字は画像に蓄積し、文字画像のLRUキャッシュを使います。
タブ非表示時は一時停止し、自動再開しません。モーション低減設定では初期状態で完成形を表示します。

## 検証

Node.js 22で、リポジトリルートから以下を実行します。

```sh
node --test portraits/tests/*.test.js
```

白領域の配置除外・乱数再現性・不規則降雨・同時落下上限・着地順の逆転・全文字の完了・フォントと外字のカバー範囲を検証します。
ブラウザーでは読み込み、再生、完成形、設定開閉、スマートフォン表示、フォント読み込み失敗時の再試行を確認します。

現在の描画は試作で承認されたCanvas 2D版です。WebGLへの移植は含めていません。
素材の条件は [NOTICE.md](NOTICE.md) を参照してください。
