# 薄膜の万華鏡 / Iridescent Kaleidoscope

操作しなくても眺め続けられる、六方向対称の手続き的な薄膜表現。

- 全体はゆっくり回転。初期値0.3は毎秒約1.12度、約322秒で一周。
- 内部模様は別の時間軸で流れる。回転を0にしても内部は動き、流れを0にすれば形を保って回転する。
- 滑らかなノイズ、連続した三角関数、固定露出を使用。時間による突然の配色切り替え・点滅・カットはない。
- 干渉色の輝度を正規化し、模様の色が変わる際の明暗差を抑える。ピクセル単位の明るさを完全に一定にするものではない。
- 速度変更は独立した角度・時間の積算値へ反映し、形や角度が急に飛ばない。

WebGL 2、1パス描画、動画・画像テクスチャ・外部ライブラリ不要。薄膜の物理光学を厳密に解く方式ではなく、干渉色を近似したグラフィックです。

リポジトリルートで `python3 -m http.server 8000` を実行し `/kaleidoscope/` を開きます。

32pxの＋から回転と流れの速さを調整。一時停止／再生・最初から、×・再クリック・Escによるパネル閉鎖に対応。最初からは意図的に初期模様へ戻ります。モーション低減設定では静止状態から開始。非表示・一時停止中は連続描画を止めます。

検証: `node --check kaleidoscope/app.js`、`git diff --check`、実ブラウザーのPC・390px幅で描画・調整パネル・停止と速度変更を確認。

## 発色調整

中間調が暗く沈まないよう、固定露出を上げて表示用ガンマを調整。色の彩度を上げ、周辺減光を弱めました。小さなナビゲーション・クレジット文字は暗色に変更し、明るい背景上で読みやすくしています。回転と内部の流れの速度は変更していません。
