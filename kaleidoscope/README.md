# 薄膜の万華鏡 / Two-colour prototype

青とピンクの2色と、その中間色だけで描くシンプルな万華鏡。前の極彩色版から空間倍率と模様の周波数を大幅に下げ、大きな六方向対称の形がゆっくり混ざる表現に変更しました。

2段のノイズと弱い1段の座標ワープを使用。8色パレット、細い等高線、色収差、ブルーム、彩度の再強調を取り除き、`mix(blue, pink, blend)`で直接出力します。1パスのWebGL 2描画で、オフスクリーンのバッファは使いません。

回転と内部の流れは独立して調整可能。初期値で約322秒で一周します。速度変更で形が飛ばない積算方式、一時停止・再生、最初から、モーション低減、非表示中の連続描画停止、コンテキスト復帰は維持。

リポジトリルートで `python3 -m http.server 8000`、`/kaleidoscope/` を開きます。ビルドや外部ライブラリは不要です。

確認: JavaScript構文チェック、git diff --check。PC・390px幅のブラウザーで描画・停止・調整UIを確認。
