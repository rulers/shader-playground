# 薄膜の万華鏡 / Iridescent Kaleidoscope

操作しなくても眺め続けられる、六方向対称の手続き的な薄膜表現。

## 動きと操作

全体は初期値で毎秒約1.12度、約322秒で一周。内部模様は別の時間軸で流れます。回転0でも内部は動き、流れ0では形を保って回転します。速度変更は独立した角度・時間の積算値へ反映し、途中で形が飛ばないようにしています。

32pxの＋から回転と流れを調整。一時停止／再生・最初から、×・再クリック・Escによるパネル閉鎖に対応。最初からは意図的に初期模様へ戻ります。モーション低減設定では静止状態から開始。非表示・一時停止中は連続描画を止めます。

## 極彩色パレットと質感

- RGBの干渉色から、ネオンピンク・アシッドグリーン・エレクトリックブルー・黄など8色相を巡るパレットへ変更。物理的な薄膜干渉の再現より、ビビッドな生成グラフィックを優先しています。
- 補色を隣接する色帯に配置し、境界はRGBの線形混色でなく色相を短い区間でつなぎます。白や灰色への中和を防ぎます。
- トーンマッピングとブルーム合成後も彩度を再調整し、淡いピンクや水色に戻らないようにしています。
- 5オクターブのfBm、3段のドメインワープ、密度の高い等高線。微細部は画面上のフットプリントで抑え、画素より細かな模様によるちらつきを軽減します。
- 白い発光の加算をやめ、ブルームも局所のネオン色から生成。暗い境界線と鮮やかな色面でコントラストを作ります。
- 色収差は高密度の模様がRGBの粒に分離しないようサブピクセルに抑え、周辺減光は維持。
- 回転・流れは従来の速度で連続的に変化します。時間による点滅や突然の配色切り替えはありませんが、補色の隣接による強い視覚的コントラストがあります。

通常のSDRキャンバスでHDR風の発光感を作ります。HDRディスプレイ出力ではありません。高輝度をRGBA8へ圧縮保存して後段で逆変換するため、量子化精度には制限があります。

## 実行・描画負荷

WebGL 2。動画・画像テクスチャ・外部ライブラリ不要。リポジトリルートで `python3 -m http.server 8000` を実行し `/kaleidoscope/` を開きます。

場の生成、抽出＋水平ぼかし、垂直ぼかし、最終合成の4パス。主描画を最大1000×750、ブルームを半解像度に制限。リサイズ時はフレームバッファを再確保し、以前の資源を解放します。コンテキスト復帰にも対応。

確認: `node --check kaleidoscope/app.js`、`git diff --check`。PC・390px幅の実ブラウザーでコンパイル、描画、停止、リサイズを確認。検証したセッションの警告・エラーログなし。GPUごとのフレームレートは未計測です。
