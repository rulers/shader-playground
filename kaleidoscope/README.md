# 薄膜の万華鏡 / Iridescent Kaleidoscope

蛍光イエローと紫の2色のマーブル模様を、六方向の鏡で折り返す万華鏡です。作品名は「薄膜」ですが、薄膜干渉の物理計算は行っていません。

## 模様の生成

先に独立した直交座標のマーブル場を定義。位置・半径・方向の違う3つの局所的な渦で座標を曲げ、弱いノイズを重ねます。太い流れの内部には従属する細い帯を入れ、広い面と細い筋を共存させています。その場の中心からずれた領域を六方向の鏡で折り返します。

色の周期には画面中心からの距離を使いません。渦の巻き込み量や中心位置がゆっくり変わり、帯に巻き込み・くびれ・折り返しが現れます。物理的な流体シミュレーションや保存則に基づく移流ではなく、連続的な座標変形による近似です。

色はイエロー `(0.85, 1, 0)` と紫 `(0.45, 0, 0.85)` の間を補間します。境界のブレンド幅には下限があり、画素幅に応じて広がります。多色パレット・ブルーム・色収差は使いません。

## 操作

- 背景の描画領域（作品名が重なる部分も含む）を1回クリック／タップするごとに、現在の回転角へ反時計回りに15度を加算します。ヘッダー・フッター・調整UIの操作では加算しません。タッチは通常のタップによる `click` を利用し、二重加算を避けています。
- 32pxの「＋」で調整パネルを開きます。「15°回転」ボタンも同じ操作で、キーボードのEnter／Spaceで利用できます。
- 「回転の速さ」は全体の自動回転を調整します。範囲は0〜1、初期値0.3で、角速度は設定値 × 0.065ラジアン／秒（初期値で約322秒／周）です。
- 「模様の流れ」は内部の変形時間の進み方を調整します。範囲は0〜1.5、初期値0.6で、自動回転とは独立しています。
- 「一時停止」は自動回転と内部の流れを止めます。停止中や回転速度0でも、クリック／タップと「15°回転」は即座に反映され、停止状態を維持します。
- 「最初から」は回転角（手動の累積分を含む）と内部の変形時間を0に戻します。速度設定と再生／停止状態は維持します。
- 「×」またはEscでパネルを閉じ、「＋」へフォーカスを戻します。OSのモーション低減設定が有効なら初回は停止状態です。ページ非表示中は連続描画を止めます。

角度0は初期状態の鏡映区間の中心軸が画面右向き（水平）になる基準です。自動回転中も、手動操作の15度はその時点の角度に累積します。内部の流れを止めれば、1回・2回・3回で15度・30度・45度の変化を確認できます。模様は60度周期の六方向対称なので、4回（60度）で見た目の向きが一巡し、24回で角度に360度が加算されます。自動回転や内部の流れが動いていれば、その間の変化も重なります。

## 実行と構成

WebGL 2の1パス描画で、外部ライブラリや画像への依存はありません。`index.html` が画面と調整UI、`style.css` がレイアウト、`app.js` が操作・時間管理・WebGL初期化、`film.frag` が模様の描画を担当します。描画解像度は縦横比を保ち、最大1000×750の範囲に制限します。

リポジトリルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/kaleidoscope/` を開きます。シェーダーを `fetch` するため、HTTP配信が必要です。WebGL 2非対応時はフッターにエラーを表示し、コンテキスト喪失時は復帰を待って描画を再初期化します。

## 確認方法

`node --check kaleidoscope/app.js` と `git diff --check` でコードを検査します。ブラウザーでは停止してから背景を複数回クリック／タップし、15度ずつ変化して4回で同じ向きに戻ること、リセットで初期状態に戻ることを確認します。調整UI・リンクが回転を起こさないこと、再生中・速度0・モーション低減設定・キーボード操作・狭い画面でも動くことを確認してください。
