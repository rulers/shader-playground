# 薄膜の万華鏡 / Marbled flow prototype

蛍光イエローと紫の2色を、中心からの同心円ではなく、渦で曲げた帯として描く万華鏡です。

## 模様の生成

先に独立した直交座標のマーブル場を定義。位置・半径・方向の違う3つの局所的な渦で座標を曲げ、弱いノイズを重ねます。太い流れの内部には従属する細い帯を入れ、広い面と細い筋を共存させています。その場の中心からずれた領域を六方向の鏡で折り返します。

色の周期には画面中心からの距離を使いません。渦の巻き込み量や中心位置がゆっくり変わり、帯に巻き込み・くびれ・折り返しが現れます。物理的な流体シミュレーションや保存則に基づく移流ではなく、連続的な座標変形による近似です。

2色の値はイエロー(.85,1,0)、紫(.45,0,.85)。境界にだけ最小限のブレンドと画素幅に応じたアンチエイリアスを入れます。多色パレット・ブルーム・色収差は使いません。

## 操作・実行

32pxの＋から回転と内部の流れを独立に調整。一時停止／再生、最初から、Escでパネル閉鎖に対応。回転は初期値で約322秒／周。モーション低減設定では静止状態から開始。非表示中は連続描画を停止します。

WebGL 2の1パス描画で、外部依存はありません。リポジトリルートで `python3 -m http.server 8000` を実行し `/kaleidoscope/` を開きます。

検証: `node --check kaleidoscope/app.js`、`git diff --check`。PCと390px幅の実ブラウザーで描画・パネル・停止・リサイズを確認。
