# fragile-geometry

作品を単独の静的HTMLとして実装。リポジトリルートで `python3 -m http.server 8000` を起動し、`http://localhost:8000/fragile-geometry/` を開きます。外部画像・ライブラリ・通信は不要です。Canvas 2Dを用い、フレーム間で位置と速度を保持して減衰する動きを描画します。

## 操作

キャンバスのクリック／タップ／ドラッグ。矢印キーで位置移動、スペースで作用。右下の四角い＋から強さ調整・一時停止・リセット。Escapeでパネルを閉じます。モーション低減設定では停止して開き、明示的に再生できます。非表示タブでは描画を止めます。

## 検証

Node構文チェックとCanvasモックで入力・UI・停止・リセット・リサイズを確認。実機での美観・動き・モバイル性能は別途確認が必要です。`REVIEW.md`にレビューと修正を記録します。
