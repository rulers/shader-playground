# 水中のインク / Ink in Water

参考映像の「右から流れ込む青灰色のインク」「厚みのある塊」「白いインクとの重なり」を、WebGL 2のフラグメントシェーダーで近似する初期試作。

参考: https://d3macfshcnzosd.cloudfront.net/010918145_main_xxl.mp4

参考動画は観察のみに使用し、動画・静止フレーム・ロゴを作品には組み込んでいません。描画はすべて手続き的に生成します。

## 実行と操作

リポジトリルートで `python3 -m http.server 8000` を実行し `/inkcloud/` を開きます。外部ランタイムやビルドは不要です。

32pxの＋から流れる速さ、濃さ、渦の細かさ、白いインクを調整。一時停止・再生・最初からに対応。×・再クリック・Escで閉じます。モーション低減設定時は静止状態から開始します。

## 描画

3次元の値ノイズをワープした密度場を72ステップのレイマーチで積算。右から左へ進む丸い先端と、軸周りのねじれを時間で変化させます。光源方向の密度をサンプルして簡易的な陰影を付けます。内部描画サイズを最大760×540に抑え、非表示中・一時停止中の連続描画を止めます。

これは流体シミュレーションではありません。物理的な巻き込み、薄膜のひだ、青白インクの実際の衝突・混合は未再現です。移流・渦度場の導入、形状の多層化、適応的なサンプリングが今後の改善点です。約46秒（初期速度0.7）で流入を繰り返します。

## 確認

`node --check inkcloud/app.js`。PCと390px幅でシェーダーのコンパイル・描画・パネル開閉・一時停止・調整値変更を実ブラウザーで確認。
