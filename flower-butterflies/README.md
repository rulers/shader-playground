# 花間の蝶 / Butterflies Among Blooms

金茶の絹地に、白・薄紅・朱の菊と濃い葉を重ね、17匹の蝶が舞う動く花鳥画。参考画像の「下部の花叢・左側の高い茎・上部の大きな余白」をもとにした手続き的な作品です。

## 起動と操作

リポジトリのルートで `python3 -m http.server 8765` を実行し、`http://localhost:8765/flower-butterflies/` を開きます。ビルド・npm install・外部CDNは不要です。WebGL 2対応ブラウザーが必要です。

- 「一時停止 / 再生」、またはボタン外でSpace：蝶の動きを切り替え。
- 「最初から」：時間を0へ戻す。一時停止中は停止を維持。
- 「文字を隠す」：絵だけを鑑賞。表示ボタン、またはEscapeで復帰。
- OSのモーション低減設定では静止して開始し、明示的な再生も可能。
- 非表示タブでは描画ループを止め、復帰時の時間飛びを抑制。

## 実装

`painting.js` がCanvas 2Dで絹の交差する繊維、葉脈、菊の重なる花弁と翅模様を生成します。添付参考画像の画素や落款・書は使用していません。

`app.js` は同梱のthree.jsで正投影の景色を描画します。背景は生成した絵の平面、蝶は左右の翅のメッシュ、胴、触角で構成。左右の翅を別々のヒンジで回転させ、位置・傾き・奥行きを変化させます。各個体は花の座標への接近と余白の回遊を滑らかに繰り返します。花は静止した絵として描き、蝶の動きで余白を生かしています。

画面の縦横比に合わせて構図を再生成し、ピクセル比は2までに制限します。WebGLコンテキスト喪失時は停止し、復帰後に再開します。
