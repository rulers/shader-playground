# 花間の蝶 / Butterflies Among Blooms

「静止した日本画の中に、生命の動きが現れる」。伊藤若冲『芍薬群蝶図』を構図の参考とし、金茶の絹地に白・薄紅・紅の芍薬と濃い葉を重ね、17匹の蝶が舞う動く花鳥画です。下部の花叢・左側の高い花・上部の広い余白を維持しています。

## 起動と操作

リポジトリのルートで `python3 -m http.server 8765` を実行し、`http://localhost:8765/flower-butterflies/` を開きます。ビルド・npm install・外部CDNは不要です。WebGL 2対応ブラウザーが必要です。

- マウスや指で画面をなぞると、近くの蝶へ小さな風を送れます。入力を止めると風と変位は滑らかに収束します。
- 右下の「＋」で調整パネルを開きます。2つのスライダーは「蝶の活動量」（初期値0.55）と「風の影響度」（0.80）。活動量0では通常の飛行が止まり、風だけを鑑賞できます。風の影響度0では入力を受けません。
- 「一時停止 / 再生」、またはボタン・入力欄の外でSpace：動き全体を切り替え。停止中は風も受けません。
- 「最初から」：個体ごとの乱数列・位置・翅・風・調整値を初期状態へ戻します。一時停止中は停止を維持。
- 「文字を隠す」：パネルを閉じて絵を鑑賞。「＋」から「文字を表示」、またはEscapeで復帰。
- Escapeでパネルを閉じ、フォーカスを「＋」へ戻します。スライダーは矢印キー、ボタンはEnter/Spaceで操作できます。
- OSのモーション低減設定では静止して開始し、明示的な再生も可能。
- 非表示タブでは描画ループを止め、復帰時の時間飛びを抑制。

## 実装

`painting.js` がCanvas 2Dで絹の交差する繊維、葉脈、芍薬の幅広い花弁と翅模様を生成します。花弁の大きさ・角度・曲率を揺らし、柔らかい陰影と巻き返しを重ねます。開いた花は雄しべを見せ、八重の花は内側の花弁で花芯を隠します。枝の分岐と葉の向き・幅・節間隔を変え、下草を重ねています。参考画像の画素や落款・書は使用していません。

`app.js` は同梱のthree.jsで正投影の景色を描画します。背景の平面・蝶の胴と触角を維持し、翅を前翅・後翅に分けています。花は静止した絵として描き、蝶の動きで余白を生かします。

`butterfly.js` は3系統の輪郭を定義し、輪郭そのものをShapeGeometryにしています。アゲハ型6匹は幅のある前翅・尾状突起のある後翅・黄地の黒い筋と眼状紋、アオスジアゲハ型6匹は細長い前翅・尾のない小さな後翅・暗い地に青緑の帯、モンシロチョウ型5匹は丸い翅・淡い白・前翅先端の暗色と黒斑です。写実的な標本再現ではなく、絵画に合わせた形状の描き分けです。色の参考は[森林総合研究所のチョウ検索表](https://www2.ffpri.go.jp/cherry/chou/kensakuhyou/2_3_1kensakuhyou.html)も参照しています。

左右それぞれの前翅と後翅に独立したヒンジ・奥行き・開閉量を持たせ、後翅を少し遅らせて動かします。翅模様のテクスチャ6枚とマテリアルは個体間で共有します。両面は同じ模様とし、形状・重なり・姿勢を優先しています。

`flock.js` が17匹全体の初期構図を決めます。種類・大きさ・姿勢には独立した乱数系列を使い、位置の候補を増やしたり画面比率を変えたりしても種類・基本サイズ・姿勢区分は変わりません。位置は各個体320候補から、すでに配置した個体との外形の余白が大きい候補を選びます。外形寸法を間隔の計算に使いますが、種類や番号から座標を直接決めません。見出しのある右上にも余白を残します。

初期姿勢は横7・斜め7・正面3（約41%・41%・18%）。同じ向きから初速と最初の目標点を作り、姿勢だけ横向きで速度は上向きという不整合を避けます。端では必要な速度成分を内向きへ反転し、姿勢も同じ方向へ合わせます。初回表示と「最初から」は同じ初期化処理を使い、リセットでは既存のメッシュを再利用して現在の画面比率に合う構図へ戻します。この間隔調整は初期化・リセット時のみで、飛行中の群れにBoidsや衝突回避を追加するものではありません。

`flight.js` は羽ばたきによる上昇・滑空・下降・花への接近・短い滞在を切り替えます。個体ごとに異なる乱数列、目標点、行動時間、速度、羽ばたきで、同じ軌跡の繰り返しを避けます。位置は速度を積分します。進行方向は通常の飛行速度と風による速度から求め、向きの変化を最短角で補間します。水平移動では横姿勢、斜め移動では斜め姿勢、縦方向では背面を見せる正面姿勢へ滑らかに移り、低速時は向きを保ちます。sinは翅のストロークや角度のラップに使い、位置の軌道を指定しません。

風はポインターの移動方向・速度から作り、距離に応じて弱めます。通常の飛行と分離した変位へ局所力を加え、減衰と弱い復元力で元の行動へ戻します。入力速度・変位・速度を制限し、タッチはPointer Eventsとポインターキャプチャで処理します。外部物理ライブラリやBoidsは使用しません。

画面の縦横比に合わせて構図を再生成し、背景テクスチャを縦1800／横3200px以内、描画のピクセル比を2までに制限します。アニメーション中にメッシュ・テクスチャ・ベクトルを生成しません。リサイズ時は古い背景を破棄し、ページ終了時はGPUリソースを解放します。WebGLコンテキスト喪失時は停止し、three.js自身の復帰処理が完了した後に再開します。

## 独自Shaderの判断

今回は導入を見送っています。標準のMeshBasicMaterialとCanvasの事前描画を維持し、新しいGLSLプログラム・uniform更新・描画パスは追加しません。

| 候補 | 標準機能との差と視覚効果 | 負荷と判断 |
| --- | --- | --- |
| 絹の繊維・反射 | GLSLなら拡大率や光に応じた微細反射を作れるが、固定カメラの絵では既存の交差線で質感を保てる | 全画面での追加計算やちらつきの可能性に見合う改善を確認できていないため見送り |
| 翅の角度による色変化 | GLSLなら角度依存の発色を加えられるが、すでに翅の回転で面積・模様が繊細に変わる | 小さな翅での効果が不確かで、装飾的な輝きを増やすため見送り |
| 花弁の陰影 | Canvasの静的グラデーションで花弁の根元・縁・巻き返しを描ける | リサイズ時だけの計算で改善できるためCanvasを採用。GLSLによる動的陰影は追加しない |

Shader版とのGPU比較測定は行っていません。60fpsは目標であり、実機での達成は未測定です。

## 検証

`node tests/flower-runtime.mjs`。390×844と1280×800それぞれで通常・モーション低減の両方を確認します。17匹の既存の風・停止・復帰テストに加え、初期配置の間隔・姿勢配分・速度との整合・実メッシュが間隔用の外形円に収まること・リサイズ後のリセットを検証します。600秒相当の飛行中、全個体に正面・斜め・左横・右横の姿勢が現れることも確認します。

実際のWebGLによる見た目の回帰テストは、ローカルHTTPサーバーで`/tests/flower-visual.html`を開きます。本番のモデル・模様・姿勢関数を使用し、3形状×4姿勢の固定フレームと、実際の飛行から抽出した12姿勢をPNG基準画像と比較します。色を除いたシルエットも比較し、色違いだけの同形状へ戻る変更を検出します。テスト用ページだけでピクセルを保存し、本番レンダラーにはpreserveDrawingBufferを指定しません。

基準画像は`tests/fixtures/flower-static.png`と`flower-flight.png`です。各セルで前景領域の差分率4.5%未満（色差24超を差分とみなす）、平均RGB誤差3未満を要求します。蝶を消した画像を意図的に作る負例も失敗することを確認します。機種差を完全に吸収するものではなく、基準画像の更新は見た目を確認してから行います。

意図して更新する場合は`/tests/flower-visual.html?record`を開き、固定姿勢・飛行姿勢の両一覧を目視確認します。ページ内`#snapshot-static`と`#snapshot-flight`のPNGを上記基準ファイルへ保存し、通常URLを再実行してください。recordモードは比較をスキップするだけで、ファイルを自動上書きしません。実施結果と制約は[VALIDATION.md](VALIDATION.md)に記録しています。

初期構図の回帰テストは`/tests/flower-initial.html`です。本番と同じ群れ・花・翅・姿勢を390×844と1280×800で描画し、各17匹の領域を`tests/fixtures/flower-initial-portrait.png`、`flower-initial-landscape.png`と比較します。色差24超の画素が領域の2.5%未満、平均RGB誤差2未満を要求し、蝶を消した負例も検出します。4秒相当飛ばしてから同じメッシュをリセットし、初期フレームと完全に同じピクセルへ戻ることを確認します。基準更新は`?record`で構図を確認後、`#initial-portrait`と`#initial-landscape`のPNGを保存して通常URLを再実行します。`#initial-preview`は横画面のJPEGで、ギャラリー画像にも使用します。
