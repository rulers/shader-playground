# タイトル

## Knowledge / Context

課題・適用範囲と、事実／仮説／提案の区別を記す。AIによる後付け解析ならその来歴と調査時点を明記し、当時の意図は一次記録がなければ「不明」とする。

## Decision / Rationale

採用案、理由、比較案と却下理由、やらないことを記す。未承認の提案を採用判断として記録しない。

## Evidence / Validation

主張ごとに根拠ファイル・コミット・PR／Issue等の一次記録を対応づける。実行した検証の環境と結果、後付け推論、未確認事項を分ける。同じAI推論に由来する資料は独立証拠と数えない。

## Reuse / Limits

再利用できる条件、制約、見直す条件を記す。

## Decision history

- 日付：誰がどの判断を行ったかを出典で確認できる範囲で、状態と変更理由を記す。不明な承認者・判断日を補完しない。
