# #57 CREASE MEMORY — 実装着手仕様

作成日：2026-10-30（JST）
ブランチ：`feature/crease-memory`


## 体験と画面の決定

生成りの厚紙一枚を、赤土色の空間へ置く。初期はほぼ平ら。低い横光が折れ目の立体感を拾う。押して引いた操作が折り癖を残し、次の変形のしやすさを変える。表面へ線を描くだけでは成立しない。

- 背景 #985b47、紙 #eee3cd、陰影 #6c4a36。紙の繊維は最初は描かず、面と稜線の明暗を優先。
- カメラPerspective、FOV35°、位置(0,3.8,5.5)、注視(0,0,0)。紙は幅3.4×奥行2.4のx/z面、中心原点、変形方向y。赤土色の影受け床はy=-.55。
- 紙は片面でなくDoubleSide。左上から低い斜光＋弱い環境光、roughness .9/metalness0。折り線に発光エフェクトを加えない。
- 構成図：[初期→操作中→操作履歴あり](storyboard.svg)。最初から多数の折り目を作らない。
- 見せ場：同じ場所を同じ量引いたとき、新品では広く曲がり、折り癖があるとそこに沿って狭く深く曲がる。

## 初期実装範囲と入力

布や紙の完全な物理シミュレーションは行わず、水平な高さ場と折り線の履歴で「履歴が次の変形を変える」性質を最小実装する。折り返し/破れ/自己衝突/裏面への反転は対象外。

紙の領域をrayと基準面y=0との交点で判定しUVを取る。pointerdownで折り線の中心を決め、左右ドラッグで紙の奥行方向へ走る折り線の傾き（角度±25°）を変え、上下ドラッグで押し込み量A=clamp(-dy/240,-.32,.32)を変える。画面座標はCSS px。操作中のUV中心は固定。線の追加はrelease時だけ。
説明文は「紙を押して上下に引く。離すと折り癖が残る」。単純なclickはA=0なので癖を増やさない。操作のキャンセル時は新しい折り癖を記録せず、既存の癖は残す。

キーボードはcanvasにfocus、左右で中心uを.05移動、上下でAを.04変更、Enterで確定、Escapeで未確定分を破棄。中心v=.5とし、キー操作で行き詰まらないよう選択位置を小さい目印で示す。

## 状態・更新・描画

model.mjsはcreateState/begin/updateInput/commit/cancel/sampleHeight/resetをexport。
state={creases:[],active:null,recovery:0}。crease={cx,cz,angle,strength}、strength範囲[-.32,.32]、最大12本。初期は空。近い線（中心距離<.15、角差<10°）は統合しstrengthをclampして加算。上限時は最も弱い線と置換、同値なら古い線を置換。上限と記録状況をパネルのstatusへ表示。永続保存はしない。

高さの基礎モデル（world単位）：
- 紙の端を保つ重み E=sin(pi*u)*sin(pi*v)。
- 各折り線に対する符号付き垂直距離dを求め、残留形状R=sum(strength*.22*exp(-d*d/(2*.055*.055)))。
- 操作点付近の履歴量M=clamp(sum(abs(strength)/.32*exp(-d0*d0/(2*.15*.15))),0,1)。d0は各既存線から操作点への距離。
- 操作中の幅w=.35*(1-.65*M)、応答振幅B=A*(1+.5*M)。新規操作線への距離sからP=B*exp(-s*s/(2*w*w))。
- height=clamp(E*(R+P),-.45,.45)。Mにより幅と振幅が変化するので、同じ入力でも過去の操作で変形が変わる。単なる残留線の加算にしない。
- release時はactiveのA*.7をcreaseへ記録。操作中のPは.25秒で0へ戻し残留Rだけにする。commit直前のPをrecoveryに保存して減衰させ、形が一フレームで跳ねないよう新旧の高さを補間。次の操作はrecoveryを0にして始める。reduced-motionは直ちに残留形状へ。
- active中もcreasesを毎フレーム増やさない。Pause中は更新しない。Resetでcreases/active/recoveryを空にする。

renderer.js：PlaneGeometry(3.4,2.4,80,56)をx/z面へ回転。毎更新で各頂点のheightを書き、computeVertexNormals。CPUで履歴/高さ、GPUで法線と光の描画。ShaderMaterialを初手で必要としない。縁の厚みや微細な繊維の追加は体験が成立した後。静止後はRAF停止。影マップは1024以下。

調整UI：折り癖の効き0..1（初期1、Mだけに掛けて比較できる）、Pause、Reset、記録本数。残留形状Rは効き0でも見えるので、同じ残留形状で反応だけを比較可能。

## 固有の受け入れ条件

- 初期は平ら。release後も稜線とその陰影が残る。Resetで初期へ戻る。
- 同一入力で履歴有/無を比較し、既存の高さRを差し引いた変形Pの幅・振幅が変わることを数値テスト。色や線が残るだけなら不合格。
- creases=0と、中心にstrength=.32の線が1本ある状態で同じA=.2を入力。後者でM>0となり幅が小さく、ピーク変形が大きいこと。効き0で差が消えること。
- 12本を超える操作、中心/端/角、A上限、キャンセル、連続ResetでNaN/穴/極端な法線反転なし。高さは±.45以内、配列上限12。
- 新品→一回→数回の3画面で「自分が触って育てた」変化を読める。線が増えるだけなら質感追加よりMと入力の関係を修正。
- 直接URL：/crease-memory/。実装後の追加先は同名ディレクトリ、トップのカードは最終段階。

- 描画は同梱済み `../third_party/three/three.module.js`（NOTICE記載0.186.1）を使う。CPUの入力・状態更新とGPUの描画を分離する。既存PortraitRendererや麺のエンジンは用途が異なるため流用しない。
- 画面の外枠はnoodle-discoの小さい正方形＋、rain/koiの開閉・Escape・フォーカス復帰を参照する。CC BY-NC-SAのrain実装をコピーせず独自実装し、独自部分はルートMIT、three.jsの既存MIT表記を維持する。
- 作品タイトル・トップへの戻りリンク・短い操作説明をHTMLで配置。右上32pxの四角い＋、パネル初期非表示、幅280px以下・モバイルは画面幅内。×/Escapeで閉じ、トリガーへフォーカスを戻す。aria-expanded/aria-controlsを同期する。
- UI操作はキャンバスのドラッグに伝播させない。作品上のみtouch-action:none。ポインターIDは一つだけ保持し、capture/releaseを使う。pointercancel/lostpointercapture/blur/タブ非表示で必ず操作を解除する。
- Pauseは運動を停止し描画を保つ。停止中は作品操作を受け付けず、調整とResetによる一回描画は可。Resetは配置・履歴・調整値を初期化し、Pauseの選択は維持。
- reduced-motion時は自律演出を止める。明示ドラッグ中は直接追従、離した後は長い揺れを省き静止させる。非表示タブでRAF停止、復帰時に経過時間を飛ばさない。
- DPR上限1.5、描画バッファは長辺1920px以下。CSS寸法と描画寸法を分け、入力はcanvas.getBoundingClientRectからNDCへ変換。resize時は入力解除しカメラと描画サイズを更新。
- WebGL初期化失敗/コンテキスト喪失時は操作を無効化し、HTMLの説明・戻りリンク・再読み込み案内を残す。初期化はtry/catch、disposeでRAF・イベント・GPU資源を解放する。

## 共通の検証手順（実装後に実行）

1. リポジトリルートで `python3 -m http.server 8000`。file://ではなくHTTPで、下記の作品URLへ直接アクセス。
2. `node --test <作品ディレクトリ>/tests/*.test.mjs`。標準node:testのみ。長時間更新で全数値が有限、dt分割の差、Reset、Pause、キャンセルを検証する。
3. Chromiumと実機Safari/Androidでポインター/タッチ、390×844・844×390・1440×900、DPR1/2、パネル開閉・キー操作・画面回転を確認。実行環境がなければ未確認と明記。
4. 非表示→復帰、reduced-motion、WebGL失敗/喪失、連続Resetで入力の固着・多重RAF・例外がないこと。
5. 60秒の操作を計測。目標はデスクトップ60fps/モバイル30fps。端末・ブラウザー・解像度・測定結果をREADMEへ残す。未達時はDPR/影解像度を下げ、核の操作は削らない。
6. 初期・操作中・操作後の3枚を保存し、本書の見せ場と照合。合格してから実レンダリングの `preview.jpg` を取得（構成図を実装プレビューとして使わない）。
