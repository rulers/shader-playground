# #06 MAGNETIC SHAPES — 実装着手仕様

作成日：2026-10-30（JST）
ブランチ：`feature/magnetic-shapes`


## 体験と画面の決定

青・朱・生成りの厚い図形6個。マットな塗装素材と柔らかな影を、明るい背景に置く。片を引くと他の片が連なり、離せば構図が落ち着く。正解の形や点数は設けない。アーチ形に戻すゲームでもない。

- 背景 #f3ebda、青 #355f9e、朱 #df6248、アイボリー #e9dfc7。黒い輪郭やネオンを避け、丸みと側面の厚みで触りたさを作る。
- カメラはOrthographic、視野高6、位置(0,0,8)。x/yが操作面。厚みz=.25程度、Keyを左上、背景の影受け平面z=-.45。片の角にごく小さいベベルを自前のExtrudeGeometryで付ける。
- 初期配置（world x,y）：(-1.5,.6),(-.7,-.3),(0,.8),(.7,-.5),(1.45,.45),(0,-1.2)。円盤2、角丸四角2、三角2、各直径/幅.6前後。生成seed固定。初期配置を完成形として強制しない。
- 構成図：[初期→操作中→解放後](storyboard.svg)。操作中はつかんだ一片が少し前に浮き、影が離れる。
- 見せ場：一片を引くと近隣が追い、近づけすぎると押し返され、別の均衡で止まる。

## 初期実装範囲と入力

マウス/単一タッチで片をつかむ。ヒットしない余白は何もしない。つかんだ片のzを.12上げ、輪郭の明度を少し上げる。配置のx/yはRayとz=0平面の交点＋初回オフセット。ドラッグ中は対象片をkinematicにし、速度0、他の片へだけ力を伝える。解放時に投げ速度を付けない。

キーボードはTabでcanvasへ、Enterで選択片を順番に切替、矢印で選択片を.1移動、Escapeで解放。選択状態をHTML statusでも伝える。SpaceはPause。

## 状態・更新・描画

model.mjsはcreateState/step/grab/move/release/resetをexport。片は{id,x,y,vx,vy,radius}、dragは{id,offset}。描画用の形状情報はrendererへ分離する。全片のcollision radius=.4、初期サイズはその中に収める。

力は現実の電磁場の再現ではなく、均衡を作る造形用の規則：
各ペアについてr=pj-pi、d=|r|、n=r/max(d,eps)。
d<.8ならiへの反発 -24*(.8-d)*n、.8<=d<1.6ならiへの引力 4*(d-.8)*(1-d/1.6)*n、それ以外0。jには逆符号。d<epsの場合はID順で固定方向nを与えNaNを防ぐ。
さらに弱い中心拘束 -0.8*p と減衰 -6*v。加速度長を20、速度長を3で制限。半陰的Euler、固定dt=1/120、最大4substep、フレーム差上限1/30。見かけ上重なったら距離.8まで位置補正する（kinematicな片は動かさず相手へ全補正、通常は半分ずつ）。

portraitではworldの縦幅を拡げ、操作域の横幅も全片が入る最低4.8を確保。拘束枠はカメラの可視領域からUI余白と半径を引いて算出。外へ出た片はclampし外向き速度を0へ。resize後は全片を再clamp。

renderer.jsは6個のExtrudeGeometry、MeshStandardMaterial、roughness .75/metalness0。影マップは1024以下。実体のx/yはmodelから受け取り、掴んだ片のzだけ描画で補間。バネの線・力の矢印を常設せず、図形の関係を動きで見せる。

調整UI：引き合う強さ0..2（初期1、引力項のみへ掛ける）、Pause、Reset。反発や中心拘束をUIに露出しない。最大速度<.005が.5秒続けばRAF停止し、入力で再開。常時ノイズ・音・粒子は追加しない。

## 固有の受け入れ条件

- 片を一つ引くと近隣も動き、遠距離の全片が同じ移動をしない。配置を狙って変えられる。
- 初期10秒・ドラッグ解放後3秒で目立つ揺れが収まることを触感確認。持続発振するなら引力を増やさず減衰/stepを修正。
- 6片同一点から始めても10000stepで有限、枠内、解消不能な重なりが持続しない。
- 力のペア対称性、距離0、つかみ中の固定、release後の復帰、Resetの再現性をテスト。
- 初期だけでなく崩した後の3配置も、色の塊・影・余白が読めること。形の均衡が弱ければ片数や装飾を増やす前に力とサイズを調整。
- 直接URL：/magnetic-shapes/。実装後の追加先は同名ディレクトリ、トップのカードは最終段階。

## リポジトリ調査と共通方針

- 確認対象：ルートREADME/index.html、rainのHTML/CSS、koi/app.js、soseki/lib/three-renderer.js、noodle-discoのREADME/HTML、third_party/three/NOTICE.md。
- 当該mainの全ツリーにAGENTS.md、SKILL.md、ルートpackage.json、GitHub Actions定義は存在しない。新しい全体ルールは追加しない。
- GitHub Pagesはmainのルートを静的配信。作品ごとのディレクトリにHTML/CSS/ES Modulesを配置し、ビルド工程・CDN・追加npm依存は不要とする。
- 描画は同梱済み `../third_party/three/three.module.js`（NOTICE記載0.186.1）を使う。CPUの入力・状態更新とGPUの描画を分離する。既存PortraitRendererや麺のエンジンは用途が異なるため流用しない。
- 画面の外枠はnoodle-discoの小さい正方形＋、rain/koiの開閉・Escape・フォーカス復帰を参照する。CC BY-NC-SAのrain実装をコピーせず独自実装し、独自部分はルートMIT、three.jsの既存MIT表記を維持する。
- 作品タイトル・トップへの戻りリンク・短い操作説明をHTMLで配置。右上32pxの四角い＋、パネル初期非表示、幅280px以下・モバイルは画面幅内。×/Escapeで閉じ、トリガーへフォーカスを戻す。aria-expanded/aria-controlsを同期する。
- UI操作はキャンバスのドラッグに伝播させない。作品上のみtouch-action:none。ポインターIDは一つだけ保持し、capture/releaseを使う。pointercancel/lostpointercapture/blur/タブ非表示で必ず操作を解除する。
- Pauseは運動を停止し描画を保つ。停止中は作品操作を受け付けず、調整とResetによる一回描画は可。Resetは配置・履歴・調整値を初期化し、Pauseの選択は維持。
- reduced-motion時は自律演出を止める。明示ドラッグ中は直接追従、離した後は長い揺れを省き静止させる。非表示タブでRAF停止、復帰時に経過時間を飛ばさない。
- DPR上限1.5、描画バッファは長辺1920px以下。CSS寸法と描画寸法を分け、入力はcanvas.getBoundingClientRectからNDCへ変換。resize時は入力解除しカメラと描画サイズを更新。
- WebGL初期化失敗/コンテキスト喪失時は操作を無効化し、HTMLの説明・戻りリンク・再読み込み案内を残す。初期化はtry/catch、disposeでRAF・イベント・GPU資源を解放する。

## 共通の検証手順（実装後に実行）

1. リポジトリルートで `python3 -m http.server 8000`。file://ではなくHTTPで、下記の作品URLへ直接アクセス。
2. `node --test <作品ディレクトリ>/tests/*.test.mjs`。標準node:testのみ。長時間更新で全数値が有限、dt分割の差、Reset、Pause、キャンセルを検証する。
3. Chromiumと実機Safari/Androidでポインター/タッチ、390×844・844×390・1440×900、DPR1/2、パネル開閉・キー操作・画面回転を確認。実行環境がなければ未確認と明記。
4. 非表示→復帰、reduced-motion、WebGL失敗/喪失、連続Resetで入力の固着・多重RAF・例外がないこと。
5. 60秒の操作を計測。目標はデスクトップ60fps/モバイル30fps。端末・ブラウザー・解像度・測定結果をREADMEへ残す。未達時はDPR/影解像度を下げ、核の操作は削らない。
6. 初期・操作中・操作後の3枚を保存し、本書の見せ場と照合。合格してから実レンダリングの `preview.jpg` を取得（構成図を実装プレビューとして使わない）。

## 2026-10-31 改訂案を反映した実装

11月1日分として実装。会話の最新改訂「動くポスター」を優先し、以前の直接ドラッグ／three.js立体／自由配置から、接近による局所的な引力／浅い厚みのCanvas 2D／初期構図への復元へ変更した。円・棒・半円・角丸四角の6片、青・朱・黒・生成りを採用。外部依存やWebGLの初期化を増やさず、輪郭と余白が主役の改訂案を実現するため。元仕様の自由配置彫刻と同一の挙動とは称さない。

model.mjsが引力・反発・復元・減衰を担当し、app.jsがCanvas描画と入力を担当。マウス接近、単一タッチ、矢印キー、Escape、Pause、Resetに対応する。検証の現在の結果と制限は magnetic-shapes/README.md に記載。
