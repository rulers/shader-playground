# PARADOX ROOM / 矛盾する部屋

2026-11-07（土）候補。奥へ反復する部屋に、異なる壁へ連なる階段を配した錯視作品です。横ドラッグで重力の向きを回し、離すと90°刻みの方向へなじみます。縦ドラッグで消失点をずらせます。

リポジトリルートで `python3 -m http.server 8000` を起動し、`http://localhost:8000/paradox-room/` を開きます。ビルド・外部素材・外部通信は不要です。

- マウス／タッチ：ドラッグで部屋の向き・消失点を操作。
- ＋：遠近の深さ・余韻、一時停止・リセット・90°回転。
- キーボード：作品へTabで移動し、左右キーで回転、上下キーで消失点、Enter／Spaceで90°回転。
- モーション低減：停止状態で開始。キー・90°回転ボタンは静止画として操作できます。

Canvas 2Dの遠近投影です。Shader・WebGL非対応端末でも同じ描画が可能です。実際に歩き回る3D空間や物理的に矛盾した接続をシミュレートするものではなく、平面投影と重力基準の変化による錯視です。22層固定、DPR最大2、非表示時に描画停止、復帰時dtリセット。
