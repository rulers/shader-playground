# PIXEL ALCHEMY / ピクセルの錬金術

2026-11-05（木）候補。90 × 60の手続き生成による夕景をドラッグすると、色のかけらが同心の秩序へ並び替わります。離すと風景へ戻ります。単なるランダムなノイズではなく、元の色を保った再構成です。

リポジトリルートで `python3 -m http.server 8000` を起動し、`http://localhost:8000/pixel-alchemy/` を開きます。ビルド・外部素材・外部通信は不要です。

- マウス／タッチ：押しながら風景をなぞる。
- ＋：変換強度・戻る速さ、一時停止・リセット・全体の組み替え。
- キーボード：作品へTabで移動し、Enter／Spaceで全体を組み替え。
- モーション低減：停止状態で開始。明示的な組み替えは静止画として確認できます。

Canvas 2Dを使用します。Shader・WebGL非対応端末でも同じ作品を描画する設計です。粒子数は5,400固定、DPRは最大2。画面非表示時は描画を停止し、復帰時のdtをリセットします。作品はブラウザー内で完結し、入力履歴の永続化はありません。
