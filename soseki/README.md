# 言葉の肖像 — 夏目漱石 × 吾輩は猫である

芥川龍之介のCanvas作品 `portraits/` から独立した、Three.jsによる作品です。
指定の添付肖像と、青空文庫『吾輩は猫である』を使っています。

リポジトリルートで静的HTTPサーバーを起動します。

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

`http://127.0.0.1:8766/soseki/` を開きます。ビルド・npm install・外部CDNは不要です。WebGL 2対応ブラウザーが必要です。`file://` には対応しません。

## 操作

原稿のクリック・タップ、Enter／Space、再生ボタンで再生と一時停止を切り替えます。「最初から」「完成形」「調整」、PNG保存、進行度の移動、設定の初期化に対応します。タブ非表示時は停止します。モーション低減時は完成形で開きます。

初期状態は『吾輩は猫である』の冒頭176文字です。作品名と作家名が浮いて消え、紙面が傾き、文字の雨が漱石の肖像を作ります。文字は本文の先頭から順番に使用し、配置上限は12,000文字です。全文データを同梱していますが、一度の肖像に全文を表示するものではありません。

## 構成

- `app.js`：この作品専用の演出・読み込み・操作。毎フレームの描画はThree.js。
- `lib/three-renderer.js`：文字アトラス、InstancedBufferGeometry、ShaderMaterial、3D紙面、Raycasterによるクリック判定。
- `lib/mapping.js`、`lib/rain.js`、`mapping-worker.js`：画像解析・文字配置と種付き乱数による降雨。芥川版を基に独立したコピー。
- `wagahai.js`：指定の青空文庫本文。ルビ・見出し・奥付を除去し、外字をUnicodeへ変換。
- `assets/`：添付肖像、原典HTML、フォントとライセンス、外字画像。

画像は全体を縦横比を保って紙面に収め、左右を切り取りません。Canvas 2Dは素材解析と文字アトラスの準備に使います。着地文字の白抜きはフラグメントシェーダーで適用します。素材の実行時アクセスは同一オリジンだけです。

`portraits/three.html` は旧URL互換のため、この作品へ移動します。

## 検証

```sh
node --test soseki/tests/*.test.js portraits/tests/*.test.js
```

配置の再現性、白抜き、不規則な降雨と着地、利用範囲のフォント・外字カバー、本文の先頭・末尾を確認します。

素材の条件は [NOTICE.md](NOTICE.md) を参照してください。
