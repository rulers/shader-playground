# リベンジの万華鏡 / Revenge Kaleidoscope

参考: Adobe Stock asset 1207640549, “Kaleidoscopic VJ Lights Loop Background” by shufilm.
https://stock.adobe.com/jp/video/kaleidoscopic-vj-lights-loop-background/1207640549

黒い余白、シアン／紫の発光パーツ、中心と周辺に繰り返す星形を観察し、独自の手続き的シェーダーで試作しました。参考映像・静止フレームは組み込んでいません。既存の /kaleidoscope/ と別の作品です。

## 構成

三角形の格子と重心座標による鏡面の反復を維持し、反射前の9つの光パーツ（三角形・対の棒・山形）の位置・角度・大きさを回転角に応じて変えます。画面全体を回転する処理は廃止しました。

累積回転角を30度単位に分け、各区間の配置を固定乱数で生成。区間内は5次補間で滑らかに移動します。境目では前区間の終点と次区間の始点が一致し、急な切り替えはありません。角度は360度でリセットせず、同じ向きに戻っても新しい配置になります。ガラス片の物理的な衝突・重力は未実装です。

光の色はシアン・紫・ピンクを維持。距離関数による芯とハローを使う通常のSDR描画です。内部の流れは微細な漂いとして独立に調整できます。回転を止めれば大きな組み替えも止まります。

追加参考: https://stock.adobe.com/jp/video/glass-kaleidoscope/63160838 （Glass Kaleidoscope）。ガラス片の配置が回転に応じて変わる構造を参考にしています。映像素材は取り込んでいません。

WebGL 2の1パス、動画・画像テクスチャ・外部ライブラリ不要。リポジトリルートで `python3 -m http.server 8000`、`/revenge-kaleidoscope/` を開きます。

## 操作

＋から回転と内部の速さを調整。「30°進める」で配置の差を比較でき、停止中も使えます。初期速度では約27秒で30度進みます。一時停止・再生、最初から。×・再クリック・Escで閉じます。モーション低減設定時は静止状態から開始し、非表示中は連続描画を停止します。

背景の描画領域（作品名の重なる部分も含む）をクリック／タップするたびに、現在の角度へ15度を加算します。ヘッダー・フッター・調整UIの操作では加算しません。通常のタップによる `click` を使い、二重加算を避けています。「15°進める」ボタンでも同じ操作ができ、Enter／Spaceに対応します。既存の「30°進める」も引き続き使えます。

停止中・回転速度0でも即座に描画と角度表示を更新し、停止状態は維持します。角度0は初期配置の基準で、画面上の方向を表すものではありません。1回・2回で15度・30度と累積し、24回で360度進みますが、配置は初期状態に戻りません。自動再生中は時間経過による変化も加わります。「最初から」で累積角度と内部の流れの時間を0に戻し、速度設定と再生／停止状態は維持します。

## 検証

`node --check revenge-kaleidoscope/app.js`、`git diff --check`。PC・390px幅のブラウザーでシェーダーのコンパイル・描画・パネル・停止・リサイズを確認。

0度・30度・60度を停止状態で比較し、単なる回転ではなく形が変わることを実表示で確認。390px幅で追加ボタン・角度表示も確認。
