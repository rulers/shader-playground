# CONURE FLIGHT — 色彩の飛来

**コンセプト**：奥から飛んできた一羽が目の前で翼を収めるまで、距離・羽ばたき・視線の関係を楽しむ。

## 参考と独自性

- 参考：https://www.scrolltide.co/#t-parrot （Parrot Hero Section）
- 参考先は鳥がカメラへ向かう動画を1回再生し、最終フレームで静止する演出。
- 本作品は映像や有償素材を複製せず、Three.jsのジオメトリとGLSL背景で描く独自のデフォルメ造形。「接近→減速→停止」の演出構造だけを参考にした。
- preview.svg は同じ羽色と形状を用いたオリジナルの案内用イラスト。実ブラウザーでのスクリーンショットではない。

## 操作

- 初回アクセス：8秒で遠方から接近し、最後は翼を落ち着かせて静止。
- ポインター移動・指ドラッグ：飛行中は進路とバンク角が変わる。接近後は首がポインターに反応。
- キャンバスのクリック・タップ、Rキー、調整UIの「もう一度飛ばす」：最初から再飛行。
- Space：停止／再生。Esc：設定パネルを閉じる。
- 右上の小さな＋：速度（0.6～1.6倍）、繰り返し飛行、停止、再飛行。
- OSの動きを減らす設定が有効なときは静止状態から開始。利用者の明示操作では再飛行可能。

## 技術

- 静的HTML・CSS・JavaScript ES Modules。ビルド不要、CDN不要。
- 同梱の ../third_party/three/three.module.js を利用。
- 頭・胴・尾・左右の翼を別々に3D造形。フラグメントシェーダーで空・太陽・ハロー・ノイズを描画。
- タブ非表示でフレーム停止。復帰時の経過時間を制限。DPRと描画ピクセル数に上限。
- WebGLコンテキスト喪失・復帰、ウィンドウリサイズ、タッチ・キーボード入力に対応する設計。

## 検証

リポジトリルートで python3 -m http.server 8000 --bind 127.0.0.1 を実行し、http://127.0.0.1:8000/conure-flight/ を開く。

確認項目：初回の飛来→静止、タップで再飛行、左右の翼の羽ばたき、ポインター反応、速度・ループ・一時停止、スマートフォン表示、モーション低減、WebGL喪失復旧。

**未確認事項**：実ブラウザーでのGLSLコンパイル、鳥の羽の重なり・向き、モバイル性能、体感速度、コンテキスト復旧。GitHubへのコミットだけでは描画検証は完了しない。
