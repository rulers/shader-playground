# 墨が鯉になる / Ink Becomes Koi

「墨と鯉（koi）」とは別作品。単色の墨が一匹の鯉へまとまり、泳いで再びほどける24秒の連続ループです。

- WebGL 2、外部ライブラリ・外部素材・ビルド不要。背景の紙目は静止しています。
- 一時停止／再生のみ。OSのモーション低減設定では鯉の姿で停止して開きます。
- リポジトリルートで `python3 -m http.server 8765` を起動し、`http://localhost:8765/ink-to-koi/` を開きます。
- `ink.frag` が墨と鯉の距離場を滑らかに補間し、共通の座標変形で流れ・尾の動きを描画します。物理流体シミュレーションではありません。
- 全ての動きは24秒周期の正弦・余弦を使います。ループ境界で乱数の再生成や絵の切り替えを行いません。
- 描画解像度は約140万画素まで。非表示タブ・一時停止時は連続描画を止めます。WebGLのコンテキスト復帰に対応します。
- WebGL 2非対応時は背景と案内文を表示します。
- 独自実装・描画プレビューともにリポジトリの [MIT License](../LICENSE) を適用します。

GitHub Pages の公開は既存と同じ `main` / ルート。公開後のパスは `/shader-playground/ink-to-koi/` です。

## 検証（2026-10-30）

ローカルHTTP配信とChromeの実描画で確認しました。

- 1280×800 / 390×844：描画成功、横はみ出しなし。0 / 6 / 12 / 18 / 23.99秒の描画画像を確認。
- 同一シェーダーに0秒と24秒を渡した画像差は全409万6000チャンネル中、差の絶対値合計69（8bit単位）。浮動小数点誤差の範囲で接続。
- 一時停止中の画像が一致、再開後は変化。モーション低減時は停止状態。
- トップの作品カードから遷移、WebGL非対応の案内、コンテキスト喪失からの再描画を確認。
- 通常描画のコンソールエラー・WebGLエラーなし。JavaScript構文・`git diff --check` 成功。

実機スマートフォンのGPU性能・Safariでの滑らかさは未確認。GitHub Pagesでの公開後確認は別途必要です。
