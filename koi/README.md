# 水のあわい / Between Depth and Light

参考: https://www.youtube.com/watch?v=eY6k6WWqufU （NHK「美の壺」OP 1、紫舟公式チャンネル）

水中を気ままに泳ぐ錦鯉と、水面に広がる波紋を眺める立体作品。旧「墨と鯉」の動きの検討から発展させています。参考映像・絵・筆文字・音楽は素材として使っていません。

## 起動・操作

リポジトリルートで `python3 -m http.server 8765` を実行し `/koi/` を開きます。WebGL 2が必要です。three.js 0.186.1を [third_party/three](../third_party/three/NOTICE.md) に同梱しており、ビルド・CDN・外部素材は不要です。

32pxの＋から速さ、体のくねり、水底の質感、匹数（1〜7）を変更できます。一時停止・再生・最初からに対応。×、再クリック、Escでパネルを閉じます。モーション低減時は静止画から開始し、再生ボタンで動き出します。

## 方式と限界

- `app3d.js`：透視投影カメラ、ライティング、水底・水面、影、UIと描画ループ。
- `fish.js`：厚みのある魚体のメッシュ、尾・胸びれ・背びれ・目を手続き生成。魚体は2145頂点。画像やモデル素材は使わない。
- 個体ごとに独立した向きを持ち、その方向へ前進する。3〜7秒ごとに少し異なる三次元の方向を選ぶ。中央や他の魚を目指す力はなく、近づいた境界だけを先読みして減速・旋回する。水面と底にも同じ考え方で戻る動きを与える。
- 遊泳状態は1/60秒の固定刻みで進め、描画時に残り時間を補間する。リセットは固定シードから再現し、画面サイズ変更時は遊泳位置の割合を保つ。頭の旋回は毎秒約43度までに制限する。
- 開始位置も画面内に分散させる。端への進行成分は距離に応じて滑らかに減らし、急な位置補正や跳ね返りを避ける。個体間の追従や中央への誘導は行わない。
- 個体ごとにずれた加速・滑走のリズムを積分し、位置を飛ばさず速さを変える。進行クロックの倍率は約0.5〜1.5、尾の周期と振幅も連動する。最初から操作では同じ動きに戻る。
- 三色の鯉と金色の鯉には、時間をずらして短い直進・加速を追加。向きの変化を抑えながら速さを上げ、直進中は魚体の揺れを最大40%抑える。端までの余裕が少ないときは直進・加速を弱め、境界から戻る動きを優先する。他の個体は普段の遊泳を続ける。
- `ripples.js`：水面近く（魚体中心y≥0.88）にいる魚から二重の波紋を生成。実際の水面高y=1.24に配置し、3.6秒で広がって消える。32枚のリングを再利用し、停止・速度調整・リセットに連動する。
- 経路の曲率に応じて胴を曲げ、頭から尾へ振幅を増す進行波で尾柄・尾びれを動かす。胸びれには別の緩やかな揺れを与える。
- 紅白・大正三色・昭和三色・丹頂・山吹黄金・浅黄・白べっ甲風の7系統を参考にした配色（厳密な品種再現ではない）。初期5匹、最大7匹。
- 水底の質感は決定論的に生成したローカルの小さなテクスチャ。柔らかい影と照明で魚体の厚みと深さを表す。
- 描画解像度は約160万画素まで。停止・非表示タブでは連続描画を止め、WebGLコンテキスト復帰にも対応。
- 旧2D描画の `app.js` / `koi.frag` は比較用ソースとして残す。現在のHTMLからは読み込まない。

`feat/koi-swim-revision` 上の未公開3D試作です。魚同士の回避・流体相互作用は未実装で、軌道が重なる場合があります。波紋は視覚効果で、物理流体計算や水面の屈折ではありません。モデルの造形と水の質感は引き続き調整できます。

## 検証

`node --check koi/app3d.js` / `koi/fish.js`、`git diff --check`。Chromeの1280×800 / 390×844で実描画、パネル開閉、1〜7匹の調整、一時停止・再開、モーション低減、コンテキスト復帰を確認。モデルの頂点が有限値で、実際に高さ・奥行きが変化することを検証。外部リクエスト・コンソールエラーなし。実機スマートフォンのGPU性能とSafariは未確認。

速度クロック倍率は約0.501〜1.497、魚体の旋回は0.1秒で0.075ラジアン以下。水面近くでの二重波紋、拡大、消失、深い位置では発生しないこと、リセットで消えることを実装モジュールから確認しています。

自由遊泳はPC用・縦長画面用の2範囲で7匹×240秒を検証。範囲内を広く移動し、端では内側へ戻ること、直進加速が残ること、リセット再現性、30fpsと60fpsで位置が一致することを確認しました。

## UI調整
