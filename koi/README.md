# 墨と鯉 / Koi on Paper

参考: https://www.youtube.com/watch?v=eY6k6WWqufU （NHK「美の壺」OP 1、紫舟公式チャンネル）

和紙のような地に描かれた鯉が、胴体から尾へ波を伝えて泳ぐ動きに着目した独自の試作。映像・絵・筆文字・音楽は素材として使っていません。番組の再現映像ではありません。

## 起動・操作

リポジトリルートで `python3 -m http.server 8000` を実行し `/koi/` を開きます。ビルドや外部依存はありません。WebGL 2が必要です。

32pxの＋から速さ、体のくねり、和紙の質感、匹数（1〜7）を変更できます。一時停止・再生・最初からに対応。×、再クリック、Escでパネルを閉じます。モーション低減時は静止画から開始し、再生ボタンで動き出します。

## 方式と限界

- 曲線軌道の接線を進行方向とする。個体IDの固定乱数で基準速度（約3倍の範囲）・緩急の周期・軌道半径を分散。正の速度変動を積分して位置を求めるため、速度が変わっても位置は飛ばない。尾の振りも個体の遊泳クロックに連動。
- 紅白・大正三色・昭和三色・丹頂・山吹黄金・浅黄・白べっ甲風の7系統を参考にした配色（厳密な品種再現ではない）。サイズ、胴の縦横比、尾びれ・胸びれの広がりも個体ごとに変える。初期5匹ですべて異なる系統を表示。
- 魚の局所座標を進行波で変形。頭は静かに、尾へ行くほど振幅を大きくする。
- 楕円と三角形の距離関数で胴、尾柄、尾びれ、胸びれを生成。
- ノイズによる朱・墨の模様、にじみ、鱗、紙の繊維を描画。
- 高負荷のボリューム描画や動画再生を使わず、1パスで描画。内部解像度は最大1280×900。
- 一時停止・バックグラウンドでは連続描画を停止。WebGLコンテキスト復帰時に再初期化。

初期試作では俯瞰の平面描画です。魚同士の回避行動・流体による相互作用・立体的なひねりは未実装で、軌道が重なる場合があります。旋回時の胴体の曲率、尾びれの扇状変形、胸びれによる制動は今後の改善点です。

## 検証

`node --check koi/app.js` と `git diff --check`。実ブラウザーのPC・390px幅でコンパイル／描画、パネル開閉、一時停止と調整値変更を確認。

## UI調整

タイトルブロックの内側余白はPCで左右32px、650px以下で左右22px。スタイル・スクリプト・シェーダーに同じ更新識別子を付け、旧キャッシュとの混在を避けます。
