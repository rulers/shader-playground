# 中央奥からの初期噴出

既存の3種類・個体数（PC180／モバイル120）・色・サイズ・GLSL羽ばたきを利用します。新しいパーティクル、描画パス、GPU属性、依存ライブラリはありません。

## 時間と軌道

- 最初の0.2秒は少数、その後は1.4秒まで不規則に連続出現。別シードの決定論的乱数で順序と間隔を割り当て、空白や大量同時発生を避けます。
- 発生源は中央の幅0.65ワールド単位、z = −31〜−39。カメラは既存のz = 26。実際のXYZ座標を動かし、透視投影によって手前ほど大きくなります。
- 各飛行の所要時間は0.9〜1.7秒、最終到達は2.95秒以内。前進速度・横方向の速度・曲がりを変え、後発個体が先発を追い抜きます。
- 元の初期配置を到達先として保持します。移動する既存の奥行き振動も含めたHermite曲線で、到達時の位置・速度を接続します。姿勢は進行方向へ最短角で追従し、終了時に向きをスナップしません。
- 既存の遠景16px下限は、各飛行の後半70%で滑らかに戻します。物理サイズを一括拡大する演出にはしません。これにより中央奥の個体が最初から巨大に見えるのを防ぎます。

`opening.mjs` はCPU上の噴出状態だけを保持します。`simulation.mjs` の通常積分には、一時的に制御している個体を除外するオプションだけを追加しました。終了した個体から既存の通常積分に戻り、全個体終了後はオープニング更新を呼びません。描画は既存の3バッチを出現順に並べ、`instanceCount` で未出現個体を隠します。Shader・輪郭・UI・色周期は変更しません。

## 操作と復帰

初回とリセットで再生。停止・非表示タブ・コンテキスト喪失中は既存の作品時計とともに停止します。リサイズは進捗を保ってX座標を補正し、コンテキスト復帰は描画資源だけを作り直します。

風は到達先ではなく表示中の位置で評価し、既存と同じ距離減衰・強さ・上限・減衰率を適用します。風で動いた位置は通常飛行へ引き継ぎます。活動量0は噴出を停止します。`prefers-reduced-motion` の初回は従来どおり通常配置で静止し、噴出を省略します。

オープニングはアクティブ経過時間×活動量で進みます。色周期は従来どおり活動量とは独立した作品時計、通常飛行・羽ばたきは従来どおり1フレーム最大0.1秒です。非常に低いfpsでは表示フレームが間引かれるため、高速な噴出の見え方は実機で確認してください。

## テスト

```sh
node tests/butterfly-void/opening.test.mjs
# テスト専用依存は既存のPlaywright / pngjsと同じ。作品側には不要。
CHROMIUM_PATH=/usr/bin/chromium node tests/butterfly-void/opening-browser.cjs
```

既存の通常飛行ブラウザー／性能テストは `mount({opening:false})` で従来の初期構図から検証します。新テストはオプションを省略し、本番と同じ噴出を検証します。`browser.cjs` は `VOID_CAPTURE_DIR` で既存の保存画像を上書きせず検証できます。

検証記録・画像・性能の制約は [OPENING-VALIDATION.md](OPENING-VALIDATION.md) を参照してください。
