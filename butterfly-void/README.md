# BUTTERFLY VOID — 蝶の虚空

「色彩をまとって飛ぶ無数の蝶が、やがて白い影となる。触れると、その群れと色彩が変化する。」

ほぼ完全な黒の空間を、色とりどりの蝶が舞います。手前・中間・奥の大きさと、正面・斜め・横の姿勢が混在します。自動モードは最初の15秒がカラー、次の15秒が白影。30秒で色彩のサイクルを繰り返します。飛行軌道自体を30秒で巻き戻すことはありません。

## 起動と操作

リポジトリのルートで起動します。既存の同梱Three.jsを使用するため、作品のビルド・npm依存・CDNは不要です。

```sh
npx --yes http-server@14.1.1 . -a 127.0.0.1 -p 8000 -c-1
```

`http://localhost:8000/butterfly-void/` を開いてください。WebGL 2対応ブラウザーが必要です。`file://` ではES Modulesを読み込めません。

- マウスを動かす／指でなぞる：その場所に、移動方向・速度に応じた風を送る。入力終了後は徐々に減衰。
- 右下の小さな「□＋」：調整パネル。色彩は「自動」「カラー」「白影」から選択。
- 活動量：通常飛行と羽ばたきの速さ。0でも風には反応し、ゆっくり羽ばたく。
- 風の強さ：0で風の入力を無効化。
- Space：一時停止／再生。停止中は入力・色彩の時計・羽ばたきも停止。
- C：自動 → カラー → 白影。手動モード中も時計は進み、自動に戻すとその時刻の色になる。
- リセット：同じ画面比率の初期構図・カラー・活動量・風の強さへ戻す。停止状態は維持。
- Esc：パネルを閉じて「＋」へフォーカスを戻す。スライダーは矢印、ボタンはEnter／Spaceで操作。

OSの「動きを減らす」設定では静止して開始し、再生操作が可能です。設定を途中で有効にした際も停止します。非表示タブは描画・時間更新を止め、復帰時に時間を飛ばしません。

## 技術構成

| 担当 | 実装 |
| --- | --- |
| Three.js 0.186.1 | 同梱の `third_party/three/`。透視カメラ、種類別の3つのMesh、InstancedBufferGeometry、リサイズ、コンテキスト管理 |
| Vertex Shader | 個体別の位相・開閉量、前後翅の遅れと奥行き差、膜の曲率、一定の自然な上反角、向きと奥行き |
| Fragment Shader | 鮮やかな個体色と広い淡い陰影。白影では模様と明暗を除いて完全な白にする |
| JavaScript | 決定論的な分散配置、通常飛行の速度・進行方向、局所的な風と減衰、入力・UI・ライフサイクル |

PCは180匹、幅600px未満で起動した場合は120匹。読みやすくした遠景の密度を抑えるため小画面の個体数を144から120にし、3つの奥行き層にサイズの違いを加え、Rounded・Elegant・Compactの実際に異なる輪郭を混在させます。初期配置は18候補から既存個体との余白を評価する方式。画面比率を変えても、個体の種類・大きさ・羽ばたきの属性は変わりません。初期位置の分散処理は初期化・リセット時だけ行います。縦画面では初期配置から左下の既存キャプションを避け、近くでは通常飛行の目標を上側へ選び直します。風で押された際までハードな壁にする補正はしません。遠景は正面換算で約16pxの高さを下限とし、単なる点になりにくくしています。

通常の飛行方向は個体ごとに0.7〜2.2秒で選び直し、短い蛇行と加減速を加えます。基本速度は1.5〜3.6 world units/s、羽ばたきは約2.2〜3.8回/s。以前の漂うテンポに対し、基本速度は約3倍、羽ばたきは約2.5倍です。手前・中間・奥の層を保ちながら奥行きにも揺れ、旋回中は体の向きに小さなひねりを加えます。活動量0では奥行きを含めて通常飛行を止め、風だけに反応します。

画面端では内向きに旋回し、反対側へのワープはしません。速度から最短角で姿勢を追従させ、低速では向きを保持します。風の距離減衰・速度制限・指数減衰は維持しています。物理エンジンや全個体間のBoidsは使いません。奥行きの変化に合わせて遠景のサイズ下限も描画時に同期し、リセットやコンテキスト復帰で初期画面を再現します。

描画は種類別の3 draw calls、geometry 3、material/program 1、texture 0です。位置・姿勢を種類別のTypedArrayへコピーし、フレーム中にメッシュ・マテリアルを生成しません。解像度を240万画素以内、DPRをPC 2／小画面1.5以内に抑え、持続的なフレーム低下では描画解像度を下げます。ページ終了時はgeometry・material・rendererを破棄し、イベントを解除。WebGLコンテキスト復帰とbfcacheにも対応します。

## 蝶の造形

独立したBezier輪郭を本作品の `shapes.js` に定義します。写実性より、柔らかな輪郭と色のリズムを重視します。既存の `flower-butterflies/` は変更しません。

- **Rounded**：幅広い丸い前翅と、ふっくらした後翅。
- **Elegant**：少し長い前翅、丸い先端、面積を確保した後翅。
- **Compact**：短い前翅と、相対的に大きい後翅。

シアン・青・緑・黄・オレンジ・ピンク・紫を全タイプで使います。翅脈・斑点・黒い縁取りを廃止し、GLSLで広い淡い陰影だけを描きます。白影は陰影も除いた完全な白です。

前後翅の分離、個体別の位相、後翅の遅れ、控えめな曲率・上反角を維持します。最大開閉角を抑え、閉じた正面姿勢や真横でも面を残します。付け根を小さな胴体の内側まで重ね、開閉時の隙間を防ぎます。曲線は1区間12分割。内側リング、別の頭部、触角のチューブを廃止し、胴体8三角形・触角2三角形に簡素化しました。正面へ向け直す補正は使いません。

色の切り替えは**アクティブな実経過時間**、飛行と羽ばたきは**最大0.1秒に制限したシミュレーション時間**を使います。低fpsでも15秒／30秒の色彩周期は遅れず、次の描画フレームに反映します。非表示・停止・コンテキスト喪失中は作品時計も停止し、復帰時に空白時間を加算しません。風・飛行アルゴリズム・UI・手動色指定は維持します。

## 参考映像との関係

参考：[Adobe Stock 57054654](https://stock.adobe.com/jp/search/video?k=%E8%9D%B6&search_type=usertyped&asset_id=57054654)。30秒の公開プレビューを、時間ごとの画面と動きの参考として確認しました。黒地、大小・方向・姿勢の混在、高彩度の蝶、後半の白いシルエットを対応させています。

実装と輪郭・配色・運動は新規制作です。元動画、音声、ウォーターマーク、元動画のフレームは、作品・プレビュー・テスト・リポジトリのいずれにも収録しません。添付と記載されていた `butterfly_void_mvp.html` は作業領域に存在せず、流用していません。

独自の体験は、局所的な風、速度と姿勢の追従、色彩の手動切り替え、鑑賞を維持する小さな操作UIです。長押しの色彩波紋はMVPを簡潔に保つため今回は含めません。

## 検証

```sh
node tests/butterfly-void/simulation.test.mjs
node tests/butterfly-void/geometry.test.mjs
node tests/butterfly-void/clock.test.mjs
node tests/butterfly-void/motion.test.mjs
# テストだけに必要。作品には追加依存なし。
# npm install --no-save playwright pngjs
# npx playwright install chromium
node tests/butterfly-void/browser.cjs
node tests/butterfly-void/shapes-browser.cjs
# システムのChromiumを指定する場合
CHROMIUM_PATH=/usr/bin/chromium node tests/butterfly-void/browser.cjs
```

ブラウザーテストは実際のThree.js・GLSL・UIを使い、画素が存在すること、カラー／白影、時間経過、マウスとタッチの風、停止・再生・リセット、復旧・リソース数を確認します。本番にテスト用グローバルは設置せず、テスト時のみ入口を置換してコントローラーを取得します。

拡大検証ページは `/tests/butterfly-void/shapes.html` です。本番と同じメッシュ・GLSLで3種類×正面／斜め／真横90°×カラー／白影を表示し、ボタンで羽ばたきを再生できます。開いた位相と閉じた位相を実際に目視確認してから、`fixtures/shapes-open.png` と `shapes-folded.png` を基準として登録しました。

`shapes-browser.cjs` は18セルの輪郭と鮮やかな色・完全な白影、正規化した白影の種類差、4位相の開閉、連続したyaw遷移、翅と胴体の白い領域の連結を確認します。画像回帰は各セルで比較し、蝶1匹を消した負例も拒否します。意図して基準を更新する場合だけ `RECORD_SHAPES=1` を付け、必ず両画像を目視確認してから通常モードを再実行してください。

`/tests/butterfly-void/benchmark.html` は実GPU測定と時計の検証用です。`performance.cjs ROOT OUTPUT.json` は同一環境のSwiftShader比較用で、比較時のみDPR 1に固定します。測定環境、Before / After画像、実測値と制約は [VALIDATION.md](VALIDATION.md) を参照してください。60fpsは実機での目標であり、ソフトウェアGPU測定を実機性能とは見なしません。
